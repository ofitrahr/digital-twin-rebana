# Rebana Landscape Twin

Prototipe *digital twin* lanskap Kawasan Metropolitan Rebana (Jawa Barat). Platform ini menampilkan:
- tutupan lahan 3D;
- perubahan lahan 2014–2022;
- skenario 2030 (BAU, Proteksi LP2B, Pesisir Tangguh);
- simulasi genangan pesisir.

Live: https://ofitrahr.github.io/digital-twin-rebana/

- **Stack:** MapLibre GL JS, OpenFreeMap, AWS Terrain Tiles. Data disiapkan dengan GeoPandas, Rasterio, dan SciPy.
- **Data:** turunan yang disederhanakan dari LULC Bappeda 2014/2022 dan pola ruang RTRW. Bersifat indikatif dan bukan dokumen resmi.
- **Penyusun:** Fitrah Ramadhan, M.Sc. Kode berlisensi MIT.
